## 📌 Project Overview

The **Web Development Practical Programs Website** is a collection of practical exercises created using **HTML, CSS, and JavaScript**.

The main purpose of this project is to organize all the Web Technology practical programs in **one simple, attractive, and easy-to-navigate website**.

The website provides separate sections for different technologies and concepts, allowing users to access and practice individual programs easily.

### 📚 The project covers:

* 🌐 HTML Practical Programs
* 🎨 CSS Practical Programs
* ⚡ JavaScript Programs
* 🧩 DOM Manipulation
* 🖱️ JavaScript Events
* 📝 Forms and Form Validation
* 🌍 Browser Features
* 💾 Web Storage
* 🚀 JavaScript Mini Projects
* 🔌 API-based Projects

# ▶️ How to Run the Project

### Step 1: Clone or Download the Repository

Download the project from GitHub or clone the repository.

### Step 2: Open the Project

Open the project folder in **Visual Studio Code**.

### Step 3: Open `index.html`

Open the main:

```text
index.html
```

### Step 4: Run the Website

You can open `index.html` directly in a browser or use the **Live Server** extension in VS Code.

### Step 5: Navigate

From the main dashboard, select:

```text
HTML Programs
CSS Programs
JavaScript Programs
```

and explore the individual practical programs.
