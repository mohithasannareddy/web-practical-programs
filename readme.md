# 🌐 Web Development Practical Programs

A complete **Web Development Practical Programs Website** created using **HTML, CSS, and JavaScript**.

This project contains a collection of practical programs covering HTML fundamentals, CSS styling, JavaScript programming, DOM manipulation, events, forms, browser features, Web Storage, and mini projects.

---

## 📌 Project Overview

The main purpose of this project is to create a single website where all practical programs are organized into separate sections.

The website contains:

- HTML Practical Programs
- CSS Practical Programs
- JavaScript Practical Programs
- DOM Manipulation
- JavaScript Events
- Form Validation
- Browser Features
- Web Storage
- Mini Projects

The website provides a simple and attractive interface for accessing each practical program.

---

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactivity and dynamic content
- **DOM** – Dynamic webpage manipulation
- **Local Storage** – Browser data storage
- **APIs** – Used in selected JavaScript mini projects
- **VS Code** – Development environment
- **Git & GitHub** – Version control and project hosting
