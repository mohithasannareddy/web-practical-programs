📚 Frequently Asked Questions

What is HTML?

HTML is used to create the structure and content of webpages.

What is CSS?

CSS is used to style webpages, including colors, layouts, spacing, fonts and animations.

What is JavaScript?

JavaScript is used to add interactivity and dynamic behavior to webpages.

What is responsive design?

Responsive design allows a webpage to adjust properly to different screen sizes.
